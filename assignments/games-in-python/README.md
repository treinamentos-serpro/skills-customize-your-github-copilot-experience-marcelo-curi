# 📘 Assignment: Jogo da Forca

## 🎯 Objective

Pratique manipulação de strings, loops, condicionais e seleção aleatória em Python ao construir um jogo da Forca interativo.

## 📝 Tasks

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo em que o programa seleciona aleatoriamente uma palavra de uma lista predefinida e o jogador tenta adivinhá-la, informando uma letra por vez. Mostre o progresso da palavra oculta após cada palpite e encerre a partida quando o jogador acertar a palavra ou esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Exibir cada letra ainda não adivinhada como `_` e revelar as letras acertadas nas posições correspondentes.
- Aceitar palpites de letras e atualizar o progresso após cada palpite.
- Controlar e exibir o número de tentativas incorretas restantes.
- Encerrar a partida quando a palavra for adivinhada ou não houver mais tentativas.
- Exibir uma mensagem de vitória ou derrota ao final da partida.
